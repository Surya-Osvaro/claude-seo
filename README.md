# Osvaro SEO & GEO Blog Writing Engine

> Complete end-to-end framework for researching, structuring, writing, and optimizing high-authority B2B blog posts for **Osvaro** (Operational Systems for High-Volume UK Immigration Law Firms).

Designed specifically to be loaded into **Claude Projects Context** as a lightweight, zero-bloat repository (~45 KB total, consuming <8% of Claude's context limit).

---

## 📚 The 8 Core Modules

| Module | Purpose | Key Focus |
|---|---|---|
| **[01-keyword-research.md](./01-keyword-research.md)** | Discovery & Search Intent | B2B keyword scoring formula, striking-distance queries, long-tail expansion, intent classification. |
| **[02-competitor-and-gap-analysis.md](./02-competitor-and-gap-analysis.md)** | SERP & Competitor Triage | Finding topic gaps, depth gaps, and authority gaps in top-ranking competitor content. |
| **[03-topic-clusters-and-internal-linking.md](./03-topic-clusters-and-internal-linking.md)** | Site Architecture & Authority | Pillar-spoke hub models, contextual internal link rules, descriptive anchor guidelines. |
| **[04-content-brief-generator.md](./04-content-brief-generator.md)** | Pre-Writing Planning | Structured brief template, H1/H2 word count targets, differentiator definitions. |
| **[05-seo-content-writer.md](./05-seo-content-writer.md)** | The Master Copywriter | B2B writing blueprints (How-to guides, comparisons), high-CTR title formulas, formatting standards. |
| **[06-geo-ai-citation-optimizer.md](./06-geo-ai-citation-optimizer.md)** | AI Search Citability (GEO) | Snippet extraction rules for Google AI Overviews, Perplexity, and ChatGPT Search. |
| **[07-eeat-and-authority-gate.md](./07-eeat-and-authority-gate.md)** | Google E-E-A-T & Quality Gate | Google's Who/How/Why test, YMYL legal compliance, anti-hallucination rules. |
| **[08-schema-and-meta-builder.md](./08-schema-and-meta-builder.md)** | Schema & Metadata | Ready-to-use BlogPosting, FAQPage, and BreadcrumbList JSON-LD code + meta tags. |

## 🚀 How to Use in Claude Projects

When interacting with the **"Osvaro — Blog Writer"** project in Claude, you can prompt it with tasks like:

1. **Keyword Research & Gap Analysis:**
   > *"Run a keyword and topic gap analysis on 'immigration law firm client onboarding bottlenecks'. Give me top quick-win keywords and competitor weaknesses."*
2. **Generate a Content Brief:**
   > *"Generate a detailed content brief using Module 04 for an article targeting 'automating sponsor licence compliance'."*
3. **Draft a Full Article:**
   > *"Using the brief above, draft a 1,800-word authoritative guide following Module 05, embedding GEO snippets from Module 06, and passing the E-E-A-T gate in Module 07."*
4. **Generate Schema & Social Metadata:**
   > *"Produce the JSON-LD BlogPosting schema, FAQPage schema, and meta title/description for this draft using Module 08."*
